# AlphaDrive

A lightweight, self-hosted file manager built for simplicity, speed, and easy deployment on small VPS servers.

## About

AlphaDrive is a minimal file management and file sharing application designed for people who want to host their own files without running a heavy stack.

It focuses on:

- Simple self-hosting
- Low resource usage
- Fast file management
- Public file and folder sharing
- A clean, modern interface
- Easy deployment on small VPS servers

## Core Philosophy

AlphaDrive is designed to stay lightweight.

The project aims to avoid unnecessary services, dependencies, and infrastructure. The application should be easy to install, easy to maintain, and comfortable to run on low-resource servers.

### Architecture

The initial architecture is planned around:

- **Go** — backend
- **SQLite** — application metadata
- **Filesystem** — file storage
- **HTML, CSS & JavaScript** — frontend

The application should be deployable as a single lightweight binary wherever practical.

## Planned Features

- File and folder management
- File uploads and downloads
- Folder navigation
- File information
- Trash and restore
- Permanent deletion
- Public file and folder sharing
- Custom share slugs
- Optional link expiry
- Optional password protection
- User authentication
- Account settings
- Responsive desktop and mobile interface
